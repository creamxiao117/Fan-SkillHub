# Context Relay Prompt

读取项目根目录的 `WORK.md`，把它作为当前任务状态的唯一来源。

如果项目存在 `RUNLOG.md`：

- 接力开始时记录时间、来源窗口、目标摘要和当前状态。
- 接力结束时记录结论、产物清单和是否继续接力。

严格基于 `WORK.md` 继续执行，不重新询问已经确定的事项。每完成一个阶段，更新：

- 已完成
- 当前状态 / 阻塞
- 下一步
- 验证方式

如果上下文使用率超过 `85%` 且任务仍未完成：

1. 先更新 `WORK.md` 和 `RUNLOG.md`。
2. 最后才创建下一次一次性接力自动化。
3. 自动化默认安排在 30 秒后，名称使用 `接力-` 前缀。

如果接力因硬失败而未完成：

- 检查 `WORK.md` 是否已有 `relay-retry=1`。
- 没有时写入该标记，并只安排一次 10 秒后的重试。
- 已有该标记时停止重试，并把失败写入 `RUNLOG.md`。

任务已完成时，将 `WORK.md` 标记为 `DONE`，不要继续创建接力。
