# Computer Use（桌面操作）

桌面操作插件，让 AI 直接操作电脑，实现跨应用自动化任务。

## 核心能力

- **窗口控制**：激活、最小化、关闭应用窗口
- **鼠标操作**：点击、拖拽、滚动
- **键盘注入**：快捷键、文本输入
- **屏幕识别**：识别屏幕上的 UI 元素
- **CAD 死锁处理**：检测并处理 CAD 应用程序死锁
- **模态对话框**：处理应用弹出的模态对话框

## 使用场景

- CAD 软件死锁恢复
- 跨应用数据搬运
- 重复性桌面操作自动化
- 软件测试中的 UI 交互
- 批量文件处理

## 触发条件

- 需要操作桌面窗口
- CAD 软件出现死锁需要处理
- 需要处理模态对话框
- 需要注入快捷键
- 用户提到"控制电脑"、"桌面操作"等关键词

## 使用边界

- **自动触发**：`invoke: model`，在需要桌面操作的场景自动命中
- **不适用**：不需要桌面操作的纯命令行/代码场景
- **安全约束**：所有桌面操作都有预览和确认机制，防止误操作
