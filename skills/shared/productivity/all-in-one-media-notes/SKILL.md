# All-in-One Media Notes（音视频转笔记）

音视频转笔记技能，一站式解决音视频内容的转写、提炼和归档需求。

## 核心能力

- **音视频转写**：将音频/视频文件转换为文字稿
- **要点提炼**：自动识别关键信息和核心观点
- **结构化笔记**：生成层次清晰的 Markdown 格式笔记
- **知识归档**：将笔记归档到知识库便于检索
- **多格式支持**：支持 MP3、MP4、WAV 等常见音视频格式

## 使用场景

- 会议录音整理
- 课程视频笔记
- 播客内容摘要
- 访谈记录转写
- 讲座/培训内容归档

## 触发条件

- 用户要求总结音频或视频
- 用户要求转写音视频内容
- 用户提到"媒体笔记"或"media notes"

## 使用边界

- **手动触发**：`invoke: user`，仅在用户明确要求时使用
- **不适用**：不需要媒体处理的纯文本工作场景
