# Browser Bridge（浏览器自动化桥接）

浏览器自动化桥接插件，支持 AI 驱动的浏览器自动化操作。

## 核心能力

- **网页导航**：访问 URL、页面跳转、标签管理
- **内容抓取**：从网页提取文本、链接、结构化数据
- **UI 测试**：前端页面元素验证、交互测试
- **表单操作**：填写表单、提交数据
- **截图取证**：页面截图、视觉回归验证
- **等待与交互**：处理异步加载、模拟用户交互

## 使用场景

- 网页内容爬取与分析
- 前端 UI 自动化测试
- 网页数据采集
- 登录流程自动化
- 页面健康检查

## 触发条件

- 需要操作浏览器或访问 URL
- 需要抓取网页内容
- 需要测试前端页面
- 用户提到"浏览器"、"browser"、"爬取"等关键词

## 使用边界

- **自动触发**：`invoke: model`，在需要浏览器操作的场景自动命中
- **不适用**：不需要浏览器的纯本地代码/文件操作场景
- **注意**：涉及登录、验证码等需要人工介入的操作会主动移交用户
